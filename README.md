# Windows Offline Auto-Installer

## About the Project
A system administration automation tool designed to streamline the post-installation setup of Windows environments. This utility automates the bulk installation of essential software applications completely offline, eliminating the need for an active internet connection after a fresh OS deployment.

This project showcases automation skills, scripting, and efficient system provisioning, drastically reducing manual setup time for IT support and system administrators.

## Key Features
* **Zero-Touch Installation:** Silently installs a predefined list of essential applications without user intervention.
* **Fully Offline:** Operates entirely without internet access by utilizing pre-packaged local installers.
* **Environment Standardization:** Ensures consistent software deployment across multiple endpoints after OS reinstallation.
* **Rapid Provisioning:** Significantly reduces IT deployment time from hours to minutes.

## Built With
* **Automation:** Scripting (Batch/PowerShell/C#)
* **Concepts:** System Administration, Automated Provisioning, Silent Installation

## Usage Note
*To comply with repository size limits, this repository contains only the automation scripts and configuration files. The actual software binaries (installers) must be placed in the designated local folder before execution.*
